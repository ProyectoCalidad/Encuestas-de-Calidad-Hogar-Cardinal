Antes de subir el archivo

  1. Abrí tu BBDD_Hogar.xlsx de siempre, con los datos ya actualizados.
  2. Anduí a Archivo → Guardar como y elegí el formato CSV UTF-8 (delimitado por comas) (*.csv).
  3. Si Excel te avisa que "algunas características no son compatibles" o que se guardará solo la hoja activa, confirmá igual — asegurate de estar parada en la hoja "Histórico" antes de guardar.
  4. Volvé acá y subí ese .csv abajo.

    Panel completo — es el mismo panel, pero con los datos ya incluidos adentro del archivo. Se abre con doble clic sin necesitar internet ni ningún otro archivo — ideal para guardarlo en una carpeta compartida (ej. la ruta de red U:\). Esta copia queda fija con los datos de hoy: si querés que se actualice, hay que generar una nueva cada vez que cargues un CSV distinto.

    Después de descargar

    1. Entrá al repositorio del panel en GitHub.
    2. Abrí data.json → ícono de lápiz, o Add file → Upload files → subí el data.json que acabás de descargar (reemplaza al anterior).
    3. Hacé commit.
    4. Esperá que el chequeo de "pages build and deployment" quede en verde (pestaña Actions) y abrí el panel con Ctrl+Shift+R.

    Informe individual por cliente

    Generá un archivo separado para un solo cliente (ej. Segurcoop, Triunfo). No necesita hosting — se envía por mail como adjunto. No incluye el Ranking por Prestador ni los comentarios de detractores (ni en el panel ni en el archivo de detalle).

    Descargar panel del cliente (.html) Descargar archivo de detalle (.csv)
    Panel del cliente: mismo panel interactivo, filtrado a esa Cía únicamente, sin pestaña de Comentarios ni Ranking por Prestador.
    Archivo de detalle: CSV con Orden de Servicio, N° de Póliza, Fecha de Servicio, Fecha de Encuesta, Estado de Encuesta y las 3 calificaciones — incluye todos los casos de esa Cía (hayan respondido o no). Es para uso interno de Cardinal, no para enviar al cliente.
    Herramienta local — el archivo nunca se sube a ningún servidor, todo se procesa en tu navegador.
